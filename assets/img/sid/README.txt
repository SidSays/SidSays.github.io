Photos of Sid for the About page.

The About page shows every image in this folder automatically, in a masonry
layout, and adds each one to sitemap-images.xml for Google.

Naming matters: the filename becomes the alt text. Use lowercase words
separated by hyphens, for example siddharth-sinha-professional-headshot.jpg,
which reads as "siddharth sinha professional headshot".

Keep each file under about 400KB and no wider than 1600px, and use copies
that have had their GPS data stripped.
