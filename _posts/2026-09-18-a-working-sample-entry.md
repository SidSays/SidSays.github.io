This entry exists so the reading page has something in it, and so you can see
every text style before you write anything real. Delete it once your first
proper entry is up.

## Writing a new entry

Create a file in the `_posts` folder named `YYYY-MM-DD-some-title.md`. The date
in the filename is what orders the archive, and the words after it become the
web address. Then put a small block at the top:

```
---
title: "The title as you want it shown"
date: 2026-09-18
---
```

Everything after that is plain Markdown. `## Two hashes` makes a heading like
the one above, `### three hashes` makes a smaller one. A blank line starts a
new paragraph. There is no publish button and nothing to configure; committing
the file is publishing it.

There is one optional line you can add alongside the date:

```
place: Somewhere worth naming
```

If it is there it shows next to the date. If it is not, nothing appears.

### The styles you have

Ordinary text runs at a comfortable reading width, roughly sixty-eight
characters, on a light background chosen because these pages are meant to be
read properly rather than glanced at. You can **emphasise** a few words, or
[link out to something](https://www.youtube.com/@SidSinha) when it helps.

> A quoted passage sits indented with a rule beside it. Useful for something
> somebody actually said, which is the kind of detail that goes first when
> nobody writes it down.

Lists work as you would expect:

- One thing
- Another thing
- A third

---

A horizontal rule gives you a clean break between two parts of a longer piece,
which is handy when a single entry covers more than one stretch of time.
